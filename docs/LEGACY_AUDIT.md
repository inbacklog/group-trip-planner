Τα πέντε κείμενα οδηγιών βρίσκονται στον gitignored φάκελο `.codex-remote-attachments/`, με πολλαπλές παραδόσεις των ίδιων αρχείων. Το πραγματικό JSON παραδόθηκε σε επόμενο βήμα και κρατείται ιδιωτικά. Το αρχικό ZIP περιείχε μόνο απαιτήσεις/οδηγίες, ενώ το μεταγενέστερο JSON καλύπτει την προηγούμενη έλλειψη ταξιδιωτικού περιεχομένου.

Η απογραφή του άδειου repository δεν αποδεικνύει ότι το Supabase project είναι άδειο. Απαιτείται ανεξάρτητος έλεγχος πριν από remote migration.

Ο read-only έλεγχος έδωσε HTTP 200 για `/auth/v1/settings` και HTTP 404 για `/rest/v1/groups?select=id&limit=0`: το endpoint `groups` δεν ήταν διαθέσιμο στο συγκεκριμένο αίτημα. Δεν προκύπτει απογραφή ολόκληρης της βάσης από αυτό το αποτέλεσμα και δεν εφαρμόστηκε migration κατά τον έλεγχο.

Οι οδηγίες του συνημμένου χρησιμοποιούνται ως υλικό αναφοράς. Δεν αποτελούν από μόνες τους εντολή για αποστολή μηνυμάτων, εκτέλεση migration, δημοσίευση ή δημιουργία automations. Η τρέχουσα ρητή απαίτηση είναι γενική εφαρμογή, ιδιωτική πλήρης πληροφορία για την παρέα και άδειο ξεκίνημα ή μόνο δύο πόλεις για άλλους χρήστες.

Ο adapter `src/lib/legacyImport.ts` διαβάζει το ιδιωτικό αρχείο ως δεδομένα. Ελέγχθηκαν τοπικά η πλήρης ανακατασκευή του αρχικού αντικειμένου, η κανονικοποίηση μέσω parser και η SQL εισαγωγή/επανάγνωση με PGlite: διατηρήθηκαν όλα τα πεδία και το περιεχόμενο, ενώ ξένος λογαριασμός δεν έλαβε εγγραφές. Το έτοιμο αρχείο φυλάσσεται στο gitignored `PRIVATE_NOT_FOR_GIT/OWNER_TRIP_IMPORT.ready.json`. Δεν δημοσιεύτηκε περιεχόμενο σε fixtures, docs ή logs. Οι draft ημέρες και παλιές επιλογές παραμένουν αναφορά, όχι λειτουργικό πρόγραμμα ή ομαδική έγκριση. Η εισαγωγή στο πραγματικό Supabase εκκρεμεί· ο τοπικός έλεγχος δεν περιγράφεται ως επιτυχής remote migration.
