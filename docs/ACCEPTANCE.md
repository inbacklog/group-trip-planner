# Αποδοχή τρέχουσας υλοποίησης

| Απαίτηση | Τοπική κάλυψη |
|---|---|
| Signup/login χωρίς ομάδα ή δεδομένα | Database και browser tests |
| Κενό ταξίδι ή ακριβώς Σαγκάη/Πεκίνο | Database και browser tests· ανεξάρτητα IDs και rollback |
| Η ιδιωτική παρέα είναι το όριο πρόσβασης | RLS/ACL negative tests για διαφορετικές ταυτότητες και forged IDs |
| Πρόσκληση στην υπάρχουσα ομάδα | Μία χρήση, λήξη, ανάκληση, login και ρητή αποδοχή |
| Αφαίρεση πρόσβασης / καθαρισμός UI | SQL μετά από αφαίρεση και browser logout |
| Όλο το πραγματικό υλικό παραμένει ιδιωτικό | Ακριβής μετατροπή και προσωρινό SQL import πραγματικού αρχείου |
| Καμία πλαστή αντιστοίχιση παλιών μελών/ψήφων | Legacy fields μόνο ως αδρανή στοιχεία αναφοράς |
| Καμία σιωπηρή διπλή δημιουργία σε retry | Request UUID για groups/trips/import/stops/items |
| Αναγνωσιμότητα σε κινητό | Responsive UI, mobile browser tests και screenshots με συνθετικά δεδομένα |

Για ακριβή commands, αποτελέσματα και όρια κάλυψης δες το [TEST_REPORT](TEST_REPORT.md). Το hosted Supabase και η δημοσιευμένη εφαρμογή χρειάζονται ξεχωριστή επαλήθευση. Το ευρύτερο handoff παραμένει αναφορά για επόμενες λειτουργίες, όπως καταγράφονται στο [PROGRESS](PROGRESS.md).
