# Ιδιωτική εισαγωγή v1

Αυτό είναι το νέο συμβόλαιο της εφαρμογής. Υποστηρίζεται επίσης αυτόματη μετατροπή του παλιού format `project-china-private-handoff-v1`. Το δοσμένο `OWNER_TRIP_IMPORT.json` ελέγχθηκε τοπικά με ακριβή ανακατασκευή όλων των αρχικών πεδίων και προσωρινή SQL εισαγωγή.

Η πλήρης δομή, τα όρια και τα δικαιώματα περιγράφονται στο [DB_CONTRACT](DB_CONTRACT.md). Ο browser διαβάζει ένα JSON έως 2 MiB, παρουσιάζει το όνομα και τα πλήθη εγγραφών και ζητά επιβεβαίωση πριν από την εισαγωγή σε νέο ιδιωτικό ταξίδι της ενεργής παρέας. Η βάση δημιουργεί νέα IDs και ελέγχει ότι ο συνδεδεμένος χρήστης είναι owner/admin.

```json
{
  "schema_version": 1,
  "kind": "private-trip",
  "trip": { "name": "Συνθετικό παράδειγμα", "currency": "EUR", "timezone": "UTC" },
  "stops": [{ "key": "stop-a", "name": "Πρώτη στάση" }],
  "activities": [{
    "title": "Παράδειγμα πρότασης",
    "stop_key": "stop-a",
    "description": "Η πλήρης περιγραφή διατηρείται ως κείμενο.",
    "why_visit": "Ο λόγος που μας ενδιαφέρει.",
    "details": {
      "local_name": "",
      "duration_minutes": null,
      "cost": { "amount": null, "currency": "EUR", "unit": "per_person", "status": "unknown" },
      "sources": [{ "url": "https://example.com/reference", "last_verified": null }]
    }
  }],
  "lodgings": [],
  "transfers": []
}
```

Το παράδειγμα είναι συνθετικό και δεν αποτελεί προεπιλογή. Μετακινήσεις/διαμονές χρησιμοποιούν `title`, προαιρετικά `stop_key` και `description`, και `details`. Οι πρόσθετες περιγραφές, ώρες, μονάδες κόστους και πηγές διατηρούνται στο `details` χωρίς αυτόματη επικαιροποίηση. Άγνωστα ποσά μένουν `null`. Δεν εισάγονται `group_id`, χρήστες, ρόλοι, authors ή ψήφοι άλλων μελών.

Το UI αποδίδει περιεχόμενο ως κείμενο. Σύνδεσμοι ανοίγουν μόνο με HTTP/HTTPS· scripts, HTML και κωδικοί σε URLs δεν επιτρέπονται ως ενεργοί σύνδεσμοι. Το import δεν εκτελεί περιεχόμενο από το αρχείο. Μια μη έγκυρη εγγραφή ακυρώνει ολόκληρη την εισαγωγή. Ίδιο request UUID με ίδιο περιεχόμενο επιστρέφει το ίδιο ταξίδι, ώστε μια επανάληψη μετά από αποτυχία δικτύου να μην δημιουργεί δεύτερο αντίγραφο.
